# Gallery photos

Drop finished lash design photos here (jpg or webp, portrait works best),
then add one line per photo to the `ELIDE_GALLERY` array at the top of
`assets/gallery.js`:

{ src: "gallery/your-photo.jpg", label: "Artsy", caption: "Manga wispy" },

The label must be one of the menu names: The Lift, Classic, Volume, Artsy,
Lash Recovery and Lift. It shows as the chip on the photo.
